# قیف ثبت نظر مشتریان

پلتفرم موبایل‌اول، فارسی و راست‌به‌چپ برای جمع‌آوری نظر مشتری با حداقل کلیک. مشتری QR را اسکن می‌کند، امتیاز می‌دهد، و اگر تجربه خوب بوده باشد بلافاصله به **پلتفرم ثبت نظر** منتقل می‌شود.

```
اسکن QR → تجربه‌تان چطور بود؟ → انتخاب ستاره
   ۴ یا ۵  → انتقال خودکار به لینک پلتفرم اصلی
   ۱ تا ۳  → فرم بازخورد خصوصی روی همین سایت
```

هیچ پلتفرم خاصی (نشان، بلد، گوگل و غیره) در کد سخت‌نویسی نشده است. مدیر، هر پلتفرمی را با نام، لینک، آیکون و وضعیت می‌سازد و یکی را به‌عنوان پلتفرم اصلی انتخاب می‌کند.

## اجرای محلی

نیازمندی: Node.js 18 یا بالاتر.

```bash
cp .dev.vars.example .dev.vars
npm install
npm run dev
```

- صفحه مشتری: http://127.0.0.1:8787/review
- پنل مدیریت: http://127.0.0.1:8787/admin
- رمز پیش‌فرض: `admin123`

## استقرار روی Cloudflare (طرح رایگان)

این پروژه یک **Cloudflare Worker** است، نه Pages. از دکمهٔ Deploy مربوط به Pages استفاده نکنید.

در **کامپیوتر خودتان** (نه داخل پیش‌نمایش):

```bash
npm install
npx wrangler login
npm run deploy
```

`wrangler login` مرورگر را باز می‌کند تا به حساب Cloudflare وصل شوید. بعد `npm run deploy` خودش:

1. Worker را می‌سازد
2. پایگاه D1 را در صورت نیاز ایجاد می‌کند
3. جدول‌ها را می‌سازد

آدرس نهایی شبیه این است:

```text
https://reviewapp.<ACCOUNT>.workers.dev/review
https://reviewapp.<ACCOUNT>.workers.dev/admin
```

رمز پنل در اولین استقرار: `admin123`

بعد از استقرار، رمز را عوض کنید:

```bash
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put SESSION_SECRET
```

دامنهٔ اختصاصی را از داشبورد Cloudflare → Workers → reviewapp → Settings → Domains وصل کنید.

### اگر استقرار خطا داد

- وارد حساب نشده‌اید → `npx wrangler login`
- اشتباهاً Cloudflare Pages را انتخاب کرده‌اید → Workers را بسازید، Pages را نه
- `database_id` جعلی در `wrangler.toml` نباشد (نسخهٔ فعلی این فایل را ندارد)

## پنل مدیریت

- **داشبورد** — بازدید، امتیازها، انتقال به پلتفرم، بازخوردها
- **اطلاعات کسب‌وکار** — نام، لوگو، توضیحات، تلفن، آدرس، رنگ‌ها
- **پلتفرم‌های ثبت نظر** — افزودن هر پلتفرم با نام، لینک، آیکون، وضعیت، انتخاب به‌عنوان اصلی
- **بازخوردها** — نظرات خصوصی امتیازهای ۱ تا ۳

QR را به این نشانی‌ها وصل کنید:

```
/review
/review?branch=branch-a
```
